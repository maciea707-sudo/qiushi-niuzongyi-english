# 秋实中学牛琮一初中一年级英语发音教材

面向电脑端家庭学习的译林英语七年级上册互动点读网页。

- 8 个单元，教材第 6—103 页，共 96 个核心学习页面、1553 个句子学习单位
- 鼠标悬浮时灰化背景，并精确框定完整句子
- 点击句子后同步显示学习卡片并播放本地英式 AI 发音
- 学习卡片包含原句、英式音标和汉语意思
- 可输入教材实际页码并按回车直达，对应网址可直接收藏或分享
- 所有图片、页面数据和音频均为静态本地资源，不调用系统朗读或外部接口

## 发音说明

网页中的声音由 AI 合成，并非教材出版社官方录音。不同角色使用不同英式音色；主要中文姓名使用人工指定的普通话音素，以减少按英语拼写误读的情况。

## 使用范围

本项目用于家庭英语学习。教材内容版权归原出版方所有。
