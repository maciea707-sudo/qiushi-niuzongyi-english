# 秋实中学牛琮一初中一年级英语发音教材

面向电脑端家庭学习的译林英语七年级上册互动点读网页。

- 完整收录教材第 0—165 页：封面与目录、8 个单元、Project、Workbook 与附录
- 共 166 个教材页面、7104 个英语学习单位
- 鼠标悬浮时降低背景亮度并精确框定文字；点击后显示学习卡片并自动播放本地英语录音
- 学习卡片包含原文、符合教材体系的英式音标和完整汉语意思
- 单词、短语、标题、填空句和完整句子均可按内容结构独立点读
- 可输入教材实际页码并按回车直达，对应网址可直接收藏或分享
- 所有图片、页面数据和音频均为静态本地资源，不调用系统朗读或外部接口

## 数据检查

运行 `python scripts/validate_site.py` 检查页码、点读范围、音频与图片文件、教材词条点击位置，以及时长异常的句子。发布流程会自动运行这项检查。

## 发音说明

网页中的声音由 AI 合成，并非教材出版社官方录音。多数句子使用原有英式音色；部分缺失或截断的录音已用本地离线女声重新生成，这些录音是美式音色，学习卡片会明确标注。主要中文姓名使用人工指定的发音文本，以减少按英语拼写误读的情况。

含有 `/w/`、`/b/` 等印刷音标的句子，将句子朗读与单独的音标录音组合播放，避免将音标读成字母名称。48 个音标的录音来自站长的[英语音标练习网站](https://maciea707-sudo.github.io/english-phonetics-for-kids/)；其中录音特别轻的 `/v/` 调高了音量。教材另外出现的 `/juː/` 使用本教材中英式发音相同的单词 *you* 的录音。第 99 页的标题 `/w/ and /v/` 作为一句完整点读；语音练习与第 130—131 页附录的音标可单独点读；第 149—163 页单词表保持音标与单词合在一起点读。句子连接部分仍为离线 SLT 女声。运行 `python scripts/repair_phonetics.py` 可重新导入站长网站的音标录音并生成静态资源，需要系统安装 Flite SLT 声库和 ffmpeg。
