# 秋实中学牛琮一初中一年级英语发音教材

面向电脑端家庭学习的译林英语七年级上册互动点读网页。

- 完整收录教材第 0—165 页：封面与目录、8 个单元、Project、Workbook 与附录
- 共 166 个教材页面、7580 个英语学习单位
- 鼠标悬浮时降低背景亮度并精确框定文字；点击后显示学习卡片并自动播放本地英式发音
- 学习卡片包含原文、符合教材体系的英式音标和完整汉语意思
- 单词、短语、标题、填空句和完整句子均可按内容结构独立点读
- 可输入教材实际页码并按回车直达，对应网址可直接收藏或分享
- 所有图片、页面数据和音频均为静态本地资源，不调用系统朗读或外部接口

## 发音说明

网页中的声音由 AI 合成，并非教材出版社官方录音。不同角色使用固定且彼此区分的英式音色；主要中文姓名使用人工指定的发音文本，以减少按英语拼写误读的情况。

## 使用范围

本项目用于家庭英语学习。教材内容版权归原出版方所有。
